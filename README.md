# DonutCore
Standalone Paper plugin (1.21.4+). No dependencies.

Build:  mvn clean package   ->  target/DonutCore.jar
Install: drop the jar in your server's /plugins folder, restart.

Commands: /bal /shards /pay /shop /sell /ah /rtp /shardshop /settings /msg /r /eco
Edit plugins/DonutCore/config.yml for prices, sidebar lines, shard shop, RTP range.
